# AGENTS.md

Guidelines and project instructions for **BALAJEE DRESSES, Aurangabad, Bihar**. Any AI agent or developer working in this workspace must strictly adhere to this document.

---

### 1. Project Overview

**BALAJEE DRESSES** is a premier family clothing and ready-made garment store located in **Aurangabad, Bihar**.

**Core Product Categories:**
- Kids Wear (Infant to Toddler)
- Men’s Wear (Formals, Casuals, Shirts & Trousers)
- Ladies’ Wear (Suits, Kurtis & Ready-Made Fashion)
- Men’s Wedding Collection (Sherwani, Indo-Western, Kurta-Pajama, Nehru Jackets & Wedding Suits)
- Kids’ Wedding Collection (Boys' Sherwani, Indo-Western, Girls' Lehenga, Gowns & Sharara sets)
- Girls’ Wear
- School Uniforms

---

### 2. Audience

Families, parents, children, men, and women living in **Aurangabad, Bihar and surrounding areas**. Customers are seeking quality clothing, variety, latest fashion, and a convenient local shopping experience.

---

### 3. Primary Goal

Every page must push visitors toward:
- Visiting the store
- Calling the store
- Sending a WhatsApp enquiry
- Submitting the customer enquiry form

Primary Contact Number: **06186357267**

---

### 4. Tech Rules

- Plain HTML, CSS, and JavaScript only.
- No frameworks.
- No build step.
- No external UI libraries.
- Use one shared `style.css` and shared JavaScript file where required.
- Fully responsive for mobile, tablet, and desktop.
- Keep the code clean, simple, and easy to maintain.

---

### 5. Design Rules

Use a **premium fashion-store design** with red, black, white, and subtle gold accents.

Prioritize:
- High-quality clothing visuals
- Clean layouts
- Large readable typography
- Premium but family-friendly appearance
- Smooth, subtle animations
- Strong CTA buttons
- Fast loading

---

### 6. Conversion Rules

Every page should prominently include relevant CTAs such as:

**WhatsApp Now | Call Now | Visit Store | Send Enquiry**

Make the customer journey simple:

**Discover collection → Get interested → WhatsApp/Call → Visit BALAJEE DRESSES**
